## Lesson Learned

Always proofread TTS-generated subtitles. Whisper is ~95% accurate but consistently misses:
- Proper nouns and brand names
- Technical jargon (regex, .txt, .md)
- Homophones in technical context (mic/Mike)
- File path formatting
