（画面：iPhone 主屏幕，打开 Shortcuts app，展示「Brain Dump」快捷指令图标，带脑子 emoji。）

旁白："它就是 iPhone 自带的「快捷指令」app 里的一个自动化。你对着手机说话，它自动转文字，加上时间戳，存成 Markdown 文件到 iCloud。不用装任何第三方软件，也不用花一分钱。一共七个步骤，我们三分钟搭完。"

[搭建步骤一：语音输入 — 0:30-1:00]

（画面：新建快捷指令 → 搜索「听写文本」→ 添加动作 → 设置「停止聆听」为「暂停后」→ 顶部重命名为「Brain Dump」。）

旁白："好，打开快捷指令，新建一个。第一步，搜索「听写文本」，加进来。这个动作会打开麦克风，把你说的话实时转成文字。关键设置：「停止聆听」选「暂停后」。这样你说多久它听多久，不会中途打断你。然后在顶部把名字改成 Brain Dump，加个脑子的 emoji。"

剪辑提示：「听写文本」高亮标注，「停止聆听：暂停后」用红色圆角框标出。


[搭建步骤二：时间戳 — 1:00-1:25]

（画面：添加「当前日期」→ 添加「格式化日期」→ 切换到自定义格式 → 输入 yyyy-MM-dd-HHmm → 展示预览结果。）

旁白："接下来加两个动作：「当前日期」和「格式化日期」。格式化日期点进去，格式选「自定义」，输入这个格式字符串：yyyy-MM-dd-HHmm。这样出来的就是年月日加小时分钟，比如 2026-04-10-1231。又干净又好排序，文件名用它最合适。"

剪辑提示：屏幕上大字叠加显示格式字符串 yyyy-MM-dd-HHmm，方便观众暂停抄写。预览结果出来时加绿色对勾动画。


[搭建步骤三：文本 + 保存 + 重命名 — 1:25-1:50]

（画面：添加「文本」动作 → 插入「听写文本」变量 → 添加「存储文件」→ 路径设 iCloud Drive/Shortcuts/journal_inbox/ → 关闭「询问存储位置」→ 添加「重新命名」→ 文件名设为格式化日期 + -brain-dump.md。）

旁白："然后加一个「文本」动作，点进去，把上面那个「听写文本」变量拖进来，这就是你的文件内容。下面加「存储文件」，位置选 iCloud Drive，路径我写的是 journal_inbox 这个文件夹，当作一个收件箱。记得把「询问存储位置」关掉，不然每次还要手动选，太麻烦。再加一个「重新命名」，把文件名改成刚才那个格式化日期，后面手动加上 -brain-dump.md。这样每个文件名都带时间戳，而且是 Markdown 格式。"

剪辑提示：文件路径用图形叠加展示：iCloud Drive > Shortcuts > journal_inbox/。「询问存储位置」开关关闭时加一个清脆的关闭音效。

旁白："最后一步，加个「显示通知」，标题写「Brain Dump 已保存」，内容放格式化日期，这样你每次用完都能看到保存成功的提示。好，七个动作，搭建完成。"
