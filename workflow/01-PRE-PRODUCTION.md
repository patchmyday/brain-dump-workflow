# Phase 1: Pre-Production

## Script Structure Template

Every PatchMyDay video follows this structure:

### 1. Hook (0:00 - 0:07) ~2-3 sentences
- Pain point or surprising fact
- "Let's fix that" promise
- Target: viewer thinks "oh that's me"

### 2. Intro (0:07 - 0:25) ~4-5 sentences
- What we're building
- Key benefit (tap, talk, done)
- Anti-features (no app, no subscription, no sign-up)
- "Let's build it from zero, right now"

### 3. Build Steps (0:25 - 2:50) ~bulk of video
- One section per logical step
- Each step: what to do + why it matters
- Include "here's the key move" moments
- Sprinkle personality ("because we're adults", "sounds like a regex incantation")

### 4. Demo (2:50 - 3:35) ~show it working
- Run the thing end-to-end
- Show real output
- Verify it worked (files app, notification)
- "Look at that timer" moment

### 5. Power Tips (3:35 - 4:15) ~rapid fire bonus
- 2-3 advanced moves
- "And this is where it gets spicy"
- Tease the next video topic

### 6. CTA (4:15 - 4:35) ~subscribe
- Tease next video specifically
- "Subscribe so you don't miss it"
- "See you in that one"
